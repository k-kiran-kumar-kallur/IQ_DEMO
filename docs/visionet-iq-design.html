            Which function gave us the best return on AI this quarter, and what's holding Delivery back?

            Sales leads on absolute value ($1.0M net), but Partners has the best return per dollar of AI cost. Partner agents run cheaply on structured data, and registrations have already reached L4.

            Delivery is at autonomy 1.9 for two reasons:

            • Status reports use four templates, so the Delivery agent misreads RAG status in about one in five.
            • Change-request alerts fire too often on fixed-price work, so project managers dismiss them.

            Standardising the status template is the single biggest unlock.
